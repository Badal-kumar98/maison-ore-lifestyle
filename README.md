## 🌟 Overview

**Maison Oré** is an artisanal lifestyle brand boutique designed with quiet luxury aesthetics, bespoke typography, and contemplative pacing. Showcases hand-thrown Kyoto ceramics, small-batch Moroccan botanicals, French flax linen, and Italian spun brass illumination.

### ✨ Key Features
- **Curated Catalogue Experience**: Browse by intentional chapters (Fragrance, Ceramics, Textiles, Lighting, Objects).
- **Interactive Cart Drawer & Drawer State**: Instant flyout cart with multi-variant handling, quantity toggling, and live price recalculations.
- **Story-Driven Product Detail Pages**: Material provenance, artisan origins, dimensions, and suggested companion pieces.
- **Editorial Journal & Stories**: Long-form visual narratives on artisan workshops and slow living philosophies.
- **Resilient Offline / Client Data Architecture**: Graceful fallback to client-side data ensuring 100% interactive store browsing across static hosts.

## 🛠 Tech Stack

- **Framework**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Routing**: React Router v7 (`HashRouter`)

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Badal-kumar98/maison-ore-lifestyle.git

# Navigate into directory
cd maison-ore-lifestyle

# Install dependencies
npm install

# Run dev server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
